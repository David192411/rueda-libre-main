3. EXPLICACIÓN DEL CONFLICTO DE ESPECIFICIDAD EN EL MENÚ (MINIRETO 10):
-------------------------------------------------------------------------
- Regla del compañero:
    #menu a { color: var(--gris-asfalto); }   --> Especificidad: (0, 1, 0, 1) [1 ID, 1 Elemento]
    .activo { color: var(--verde-ruta); }    --> Especificidad: (0, 0, 1, 0) [1 Clase]

- Causa del problema:
  La regla con el ID `#menu a` tiene un valor de especificidad superior (101 puntos) respecto a la clase `.activo` (10 puntos). Por orden de cascada y especificidad, el navegador ignora `.activo`.

- Solución aplicada (sin usar !important ni inline styles):
  Se combinaron los selectores a `#menu a.activo`, cuya especificidad aumenta a (0, 1, 1, 1) [1 ID, 1 Clase, 1 Elemento = 111 puntos], ganando el conflicto limpiamente.


4. MEDICIÓN DEL MODELO DE CAJA EN TARJETAS (MINIRETO 11):
------------------------------------------------------------
Medición realizada en DevTools (Computed) sobre la tarjeta <article class="tarjeta">:
- Ancho asignado / disponible: 100% del main (~976px)
- Padding: 32px (2rem) a izquierda y derecha.
- Borde: 1px a izquierda y derecha.

a) Con box-sizing: content-box:
   Ancho Total = Ancho del Contenido (976px) + Padding (64px) + Bordes (2px) = 1042px.
   Resultado: Desbordamiento horizontal del contenedor padre.

b) Con box-sizing: border-box:
   Ancho Total = 976px exactos. El padding y el borde se absorben internamente.
   Resultado: Ajuste perfecto y alineado.
